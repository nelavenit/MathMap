**Statement.** For any vector space $V$ over a field $\mathbb{F}$ there exists a [[Hamel Basis|Hamel basis]].
$\blacktriangle$ 

| Proof using [[Zorn's Lemma\|Zorn's lemma]]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Proof using [[Zermelo's Theorem]]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Consider $P$ – set of all linearly independent subsets of $V$ with a relation $⊆$.<br>Let's verify [[Partial Order\|poset]] $\mathbb{P} = (P,⊆)$ satisfies the lemma condition: if $\{p_i\}_{i∈I} ⊆ P$ is a [[Linear Order (Chain)\|chain]], then $\bigcup_{i∈I} p_i$ is also a linearly independent set:<br>assume the opposite, i.e. $∃ v_1 ∈ p_{j_1}, v_2 ∈ p_{j_2}, \ldots, v_k ∈ p_{j_k}$ and $a_1 ... a_k ∈ \mathbb{F}$ s.t. $∑_{r=1}^k a_r v_r = \vec{0}$, but $\{p_{i_r}\}_{r=1}^k$ is a finite chain $\implies$ there is a [[Least and Greatest Elements\|greatest element]] $p_j$ s.t. $\forall r\ p_{i_r} ⊆ p_j$ $\implies$ $v_1,v_2 ... v_k ∈ p_j$ — contradicts $p_j$ being a linearly independent set $\implies$ $\bigcup_{i \in I} p_i \in P \implies$ it is an [[Lower and Upper Bounds\|upper bound]] for $\{p_i\}_{i \in I}$ $\implies$ by Zorn's lemma $\exists p \in \text{Max}(\mathbb{P})$ – this would be a basis: it satisfies (1) by definition of $P$ and (2), because else an element that can't be represented can be added to the $p$ without breaking its linear independence — contradicts the [[Minimal and Maximal Elements\|maximality]] of p. | (similar to the proof of (WO $\Rightarrow$ Zorn's))<br>Consider $I$ be a set of cardinality strictly greater than such at $V$. We get $\mathbb{I}=(I,≤)$ by [[Well-Ordered Set\|well-ordering]] $I$ using Zermelo's theorem. Now let's build $f:I→V$ by transfinite recursion: $f(i):=$element of $V$ that can't be represented as a linear combination of elements of $\{f(j)\}_{j<i}$.<br>If at some step there is no such element, then we found a basis. Else we got an injective $f: I = V$ (assume it's not injective, then at some point we assigned $f(i)=v$ where $v$ was already an image of $j < i$ $\implies$ $v$ can be represented as $\mathbb{1}*v$ — contradiction to the the choice of $f(i)$), which contradicts $I$ having a strictly greater cardinality than $V$. |
