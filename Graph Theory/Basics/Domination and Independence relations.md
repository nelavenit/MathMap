**Statement 1.** Let $\mathbb{G} = (G, E)$ be a [[Graph|graph]], $I \subseteq G$. Then $I$ is [[Independent Set|maximal independent set]] of $\mathbb{G} \iff I$ is independent [[Dominating Set|dominating]] set of $\mathbb{G}$.
$\color{red}\text{Proof}$ is a simple exercise.

**Statement 2.** Let $\mathbb{G} = (G, E)$ be a graph, $I \subseteq G$. Then $I$ is maximal independent set of $\mathbb{G} \implies I$ is  a minimal dominating set of $\mathbb{G}$.
$\color{red}\text{Proof}$ is a simple exercise.
