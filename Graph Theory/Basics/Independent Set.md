**Definition.** Let $\mathbb{G} = (G, E)$ be a [[Graph|graph]], then $I \subseteq G$ is called an <u>independent set of </u>$\mathbb{G}$ if no elements of $I$ are [[Graph|adjacent]] in $\mathbb{G}$.

**Definition.** Let $\mathbb{D} = (D, A)$ be a [[Directed Graph|digraph]], then $I \subseteq D$ is called an <u>independent set of </u>$\mathbb{D}$ if no elements of $I$ are [[Directed Graph|adjacent]] in $\mathbb{D}$.

**Definition.** Let $\mathbb{G} = (G, E)$ be a graph (digraph), then $I \subseteq G$ – an independent set of $\mathbb{G}$ is called <u>maximal</u> if there is no $I'$ such that $I \subsetneq I' \subseteq G$ and $I'$ is an independent set of $\mathbb{G}$. In other words, $I$ is a [[Minimal and Maximal Elements|maximal element]] in the order of all the independent sets of $\mathbb{G}$ ordered by inclusion.


**Remark.** Maximal independent set need not be maximal in cardinality.
