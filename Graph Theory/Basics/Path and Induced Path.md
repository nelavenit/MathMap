**Definition.** A finite [[Graph|graph]] $\mathbb{P} = (P, E)$ is a <u>path graph</u> if its vertices can be enumerated as $p_1,\ldots,p_{|P|}$such that
$$(p_i,p_j)\in E\ \Longleftrightarrow\ |i-j|=1.$$

**Definition.** Let $\mathbb{G} = (G, E)$ be a graph and $\mathbb{P}$ be a [[Subgraph|subgraph]] of $\mathbb{G}$. Then $\mathbb{P}$ is called a <u>path subgraph</u> of $\mathbb{G}$ if it is a path graph.

**Definition.** Let $\mathbb{G} = (G, E)$ be a graph and $\mathbb{P}$ be an [[Induced Subgraph|induced subgraph]] of $\mathbb{G}$. Then $\mathbb{P}$ is called an <u>induced path</u> of $\mathbb{G}$ if it is a path graph.
