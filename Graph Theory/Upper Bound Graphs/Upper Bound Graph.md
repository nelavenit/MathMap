**Definition.** Let $\mathbb{P} = (P, \leq)$ be a [[Partial Order|poset]]. We define the [[Graph|graph]] on the same set of vertices $UB(\mathbb{P}) = (P, E)$ with $(x,y) \in E \iff x$ and $y$ have a common [[Lower and Upper Bounds|upper bound]] in $\mathbb{P}$. We call this graph an <u>upper bound graph of</u> $\mathbb{P}$.
**Definition.** We call a [[Graph|graph]] $G$ <u>upper bound</u> if there exists a poset $\mathbb{P}$ s.t. $G = UB(\mathbb{P})$.
