**Definition.** Let $P$ be a set and $\leq$ be a [[Relation and Relational Structure|binary relation]] on $P$. Then $\leq$ is called an <u>order relation</u> or <u>ordering</u> if it is:
1. [[Reflexivity|Reflexive]]
2. [[Transitivity|Transitive]]
3. [[Antisymmetry|Antisymmetric]]
In other words if $(P,\leq)$ is a [[Preorder|preorder]] and $\leq$ is [[Antisymmetry|antisymmetric]].

**Definition.** Let $P$ be a set and $\leq$ be a partial order relation on $P$. Then the pair $(P, \leq)$ is called a <u>poset</u> (short from "partial order set") or an <u>order</u>.

**Definition.** Let $P$ be a set and $<$ be a binary relation on $P$. Then $<$ is called a <u>strict order relation</u> or <u>strict ordering</u> if it is:
1. [[Irreflexivity|Irreflexive]]
2. [[Transitivity|Transitive]]
A pair $(P, <)$ is called a <u>strict order</u>.

**Statement.** We would mostly use $\leq$, because strict and "unstrict" ordering are in one-to-one relation $\leq \equiv (< \bigcup =)$.
$\color{red}\text{Proof}$ is an exercise.

**Notation.** We would denote posets with **Blackboard Bold** letters, e.g. $\mathbb{P} = (P, \leq_P),\ \mathbb{Q} = (Q, \leq_Q)$.

**Remark.** The common names for $\leq$ are also <u>partial ordering</u> and <u>partial order relation</u>.
**Remark.** The common names for $<$ is also <u>strict partial order relation</u> and <u>strict partial ordering</u>.
**Remark.** The common names for a poset are also <u>partial order</u>, <u>partially ordered set</u> and <u>ordered set</u>.
**Remark.** In some sources (e.g. @schroderOrderedSetsIntroduction2016) ordering and order are synonyms meaning the relation, we would avoid such naming for unambiguity.
