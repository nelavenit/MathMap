**Definition.** Let $\mathbb{P} = (P, \leq)$ be a [[Partial Order|poset]]. [[Subposet]] of four elements $a,b,c,d \in P$ is called a <u>N'-suborder</u> if 
$$\begin{cases}
a < b \succ c < d \\
a \nsim c \\
b \nsim d \\ 
\end{cases}$$

**Definition.** A poset $\mathbb{P} = (P, \leq)$ is called <u>N'-free</u> if it contains no N'-suborder. 

**Statement.** Every [[Proper N-Freeness|proper N-suborder]] is an N'-suborder, hence [[Proper N-Freeness|proper N-freeness]] implies N'-freeness.
$\color{red}\text{Proof}$ is a trivial exercise.
