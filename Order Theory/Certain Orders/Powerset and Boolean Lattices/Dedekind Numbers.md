**Definition.** <u>N<sup>th</sup> Dedekind number</u> is a number of [[Antichain|antichains]] in the [[Powerset Lattice|powerset lattice]] of an $n$-element set, i.e. in $(\mathcal{P}(\{1,2,\ldots,n\}), \subseteq)$. 

**Notation.** While discussing Dedekind numbers we would denote the n<sup>th</sup> one by $D_n$.

**Examples.** 
1. $D_0 = 1$, the only antichain is an empty set
2. $D_1 = 3$   ![[2nd Dedekind Number Calculation.png]]
3. $D_2 = 6$
   ![[3rd Dedekind Number Calculation.png|400]]
4. $D_4 = 20$
