**Definition.** Let $\mathbb{C} = (C, \leq)$ be a finite [[Linear Order (Chain)|chain]]. We call a <u>length</u> of $\mathbb{C}$ the value $|C|-1$, denoted as $l(\mathbb{C}):=|C|-1$, i.e. number of [[Lower and Upper Covers, Adjacence|cover]] pairs in $\mathbb{C}$.

**Notation.** Same way for any [[Partial Order|poset]] $\mathbb{P} = (P, \leq)$ and $C \subseteq P$ – chain in $\mathbb{P}$ we denote $l_{\mathbb{P}}(C)$ the length of the $(C, \leq|_{C \times C})$. When order $\mathbb{P}$ is obvious from the context we would write simply $l(C)$.

**Remark.** Similarly to the [[Fence|length of the fence]] and length of the path in a graph we call a length the number of edges in the Hasse diagram/graph diagram.
**Remark.** Note this differs from the [[Height|height]] of the chain, which is $\text{length} + 1 = |C|$.
