**Definition.** Let $\mathbb{P} = (P, \leq)$ be a [[Partial Order|poset]]. A [[Linear Order and Chain|chain]] $C \subseteq P$ is called a <u>maximal chain</u> if it can't be extended to a larger chain (antichain), i.e. it is [[Minimal and Maximal Elements|maximal]] in the set of all chains in $\mathbb{P}$ with respect to set inclusion, in other words, there is no $c \in P\setminus C$ s.t. $C \cup \{c\}$ is a chain.
