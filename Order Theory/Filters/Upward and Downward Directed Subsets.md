**Definition.** Let $(P, \leq)$ be a [[Partial Order|poset]], $C \subseteq P$ is called <u>downward directed</u> if $\forall c_1, c_2 \in C \; \exists d \in C \text{ s.t. } c_1 \geq d \leq c_2$, i.e. $\{c_1, c_2\}$ has a [[Lower and Upper Bounds|lower bound]] in C. Set C is called <u>upward directed</u> if $\forall c_1, c_2 \in C \; \exists u \in C \text{ s.t. } c_1 \leq u \geq c_2$, i.e. $\{c_1, c_2\}$ has an [[Lower and Upper Bounds|upper bound]] in C.

**Statement.** Being downward directed and being upward directed are [[Dual Properties|dual properties]].
$\color{red}\text{Proof}$ is a trivial exercise.

**Remark.** In some fields Upward Directed of Downward Directed is called just <u>Directed</u>, for example in forcing theory where either downward or upward directed is used, but using both is not that common @halbeisenCombinatorialSetTheory2017.
