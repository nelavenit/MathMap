**Open problem (The automorphism problem).** Is it true, that for a sequence of [[Partial Order|posets]] of increasing size the fraction of [[Order Automorphism|automorphisms]] in the set of [[Order Endomorphism|endomorphisms]] goes to zero, i.e.  $$\lim_{n\rightarrow \infty} \max_{|P| = n} \frac{|Aut(\mathbb{P})|}{|End(\mathbb{P})|} = 0,$$where $\mathbb{P} = (P, \leq)$ is a poset.

**Intuition.** From [[Exponential Lower Bound for End(P) - Aut(P)]] we get the lower bound for a difference, but not for a fracture.
