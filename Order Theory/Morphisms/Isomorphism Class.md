**Definition.** Let $\mathbb{P}$ be a [[Partial Order|poset]], the class of all orders that are [[Order Isomorphism|isomorphic]] to $\mathbb{P}$ is called an <u>isomorphism class</u> of $\mathbb{P}$ and is denoted as $[\mathbb{P}]$.

**Intuition.** If $\mathbb{P} \neq \emptyset$ then $[\mathbb{P}]$ is a proper class, so to avoid problems we would often specify the allowed underlying set for posets so that $[\mathbb{P}]$ be a set.
