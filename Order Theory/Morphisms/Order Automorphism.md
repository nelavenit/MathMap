**Definition.** Let $\mathbb{P} = (P, \leq)$ be an [[Partial Order|order]], $f: P → P$ - [[Order Isomorphism|order isomorphism]]. Then $f$ is called an <u>order automorphism</u>. 
In other words automorphism is an isomorphic self-map.
In other words automorphism is such [[Order-preserving map (Order Homomorphism)|homomorphism]] that it is both [[Order Endomorphism|endomorphism]] and isomorphism.

**Examples.** 
1. Identity function on any order
2. ![[Order Automorphism Example 01.png]]
3. $\mathbb{Z}$ with natural ordering and $f: n \mapsto n+1$

**Intuition.** Automorphism is a way to describe "symmetry" in a structure: for example if an order diagram is symmetrical in relation to vertical axis going through the middle, then the reflection across this axis would be an automorphism.

**Notation.** We denote the set of all automorphisms on $\mathbb{P}$ by $\underline{Aut(\mathbb{P})}$.

**Statement.** Being an automorphism is [[Self-dual Properties|self-dual]].
$\color{red}\text{Proof}$ is a simple exercise.
