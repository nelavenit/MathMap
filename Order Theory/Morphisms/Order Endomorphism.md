**Definition.** Let $\mathbb{P} = (P, \leq)$ be an [[Partial Order|order]], $f: P → P$ - [[Order-preserving map (Order Homomorphism)|order homomorphism]]. Then $f$ is called an <u>order endomorphism</u> (alternatively <u>order-preserving self-map</u>).

**Examples.** 
1. ![[Order Endomorphism Example 01.png]]
2. ![[Order Endomorphism Example 02.png]]
3. $\mathbb{N}$ with natural ordering and $f : n \mapsto n + 1$
4. Any constant function on any order, i.e. $f$ s.t. $\exists p_0 \in P\  \forall p \in P\ f(p) = p_0$

**Notation.** We denote the set of all endomorphisms on $\mathbb{P}$ by $End(\mathbb{P})$.

**Statement.** Being an endomorphism is [[Self-dual Properties|self-dual]].
$\color{red}\text{Proof}$ is a simple exercise.
