**Definition.** Let $\mathbb{P} = (P, \leq_P)$ and $\mathbb{Q} = (Q, \leq_Q)$ be [[Partial Order|posets]], $f: P \rightarrow Q$ is called a <u>strict order homomorphism</u> if $\forall p_1, p_2 \in P \text{ we have } p_1 <_P p_2$ implies $f(p_1) <_Q f(p_2)$.

**Definition.** If $f$ is a self-map, then we call it <u>strict order endomorphism</u>.

**Remark.** Other common names for strict order homomorphism are <u>strictly isotone map</u>, <u>strictly order-preserving map</u>, <u>strictly increasing function</u>. Sometimes it's also called <u>strictly monotone map.</u> For brevity we would call it also just "strict homomorphism" ("strict endomorphism") when orders/[[Preorder|preorders]] are the only structures in consideration.

**Statement.** If $f$ is a strict order homomorphism, then $f$ is an [[Order-preserving map (Order Homomorphism)|order homomorphism]].
$\color{red}\text{Proof}$ is a trivial exercise.

**Statement.** If $f$ is an [[Order Isomorphism|order isomorphism]], then $f$ is a strict homomorphism.
$\color{red}\text{Proof}$ is a simple exercise.

**Statement.** If $f$ is an order embedding, then $f$ is a strict homomorphism.
$\color{red}\text{Proof}$ is a simple exercise.

**Statement.** Being a strict order homomorphism is [[Self-dual Properties|self-dual]],, i.e. $f$ is a strict homomorphism from $\mathbb{P}$ to $\mathbb{Q}$ iff $f$ is a strict homomorphism from $\mathbb{P}^d$ to $\mathbb{Q}^d$.
$\color{red}\text{Proof}$ is a trivial exercise.
