**Definition.** Let $\mathcal{C}$ be the set of all [[Isomorphism Class|isomorphism classes]] of [[Partial Order|orders]] with an underlying set contained in $\mathbb{N}$. The <u>deck</u> of a poset $\mathbb{P}$ is the function $D_\mathbb{P} : \mathcal{C} \to \mathbb{N}$ s.t. for each $[C] \in \mathcal{C}$ we have that $D_\mathbb{P}([C])$ is the number of [[Card|cards]] of $\mathbb{P}$ that are [[Order Isomorphism|isomorphic]] to the $C$.
