**Definition.** An <u>order invariant</u> $\alpha (\cdot)$ of an [[Partial Order|order]] is a function from the class of all orders to another set or class s.t. if posets $\mathbb{P}$ and $\mathbb{Q}$ are [[Order Isomorphism|isomorphic]], then $\alpha(\mathbb{P}) = \alpha(\mathbb{Q})$.

**Notation.** When no confusion arises we would say simply <u>invariant</u> for brevity.

**Examples.** 
1. Number of elements
2. Number of comparabilities
3. [[Deck]]

**Remark.** Sometimes invariant is called a <u>parameter</u>.
