**Intuition.** Often it is easier to prove that an [[Partial Order|order]] [[Isomorphism Class|isomorphism class]] possesses a weaker property than [[Reconstructibility|reconstructibility]]. And it can be used to prove the reconstructibility.

**Definition.** Class of orders $\mathcal{K}$ is called <u>recognizable</u> if for each set $\mathbb{P} ∈ \mathcal{K}$ and any ordered set $\mathbb{Q}$ we have $D_\mathbb{P} = D_\mathbb{Q}$ implies $\mathbb{Q} \in \mathcal{K}$.

**Statement.** Every reconstructible order class is recognizable.
$\color{red}\text{Proof}$ is a trivial exercise.

**Intuition.** The idea of recognizability is if we have some property of decks s.t. $P \in \mathcal{K} \Leftrightarrow D_p$ possesses this property, then we can first check if $P \in \mathcal{K}$ before trying to reconstruct it and this additional info will help us do the reconstruction. For example see proof of [[Poset with Least or Greatest Element is Reconstructible]].
