**Definition.** We say a [[Partial Order|poset]] $\mathbb{P}$ is <u>reconstructible</u> from its [[Deck|deck]] $D_\mathbb{P}$ if all posets $\mathbb{Q}$ with $D_\mathbb{P} = D_\mathbb{Q}$ are [[Order Isomorphism|isomorphic]] to $\mathbb{P}$.
**Definition.** A class $\mathcal{K}$ of posets is <u>reconstructible</u> if each of its members $P∈\mathcal{K}$ is reconstructible.

**Examples.**
1. [[N-Order is reconstructible]]
2. [[Poset with Least or Greatest Element is Reconstructible|The class of posets with the least element is reconstructible]]
3. [[Poset with Isolated Point is Reconstructible|The class of posets with an isolated point is reconstructible]]

**Definition.** An [[Order Invariant|order invariant]] is called <u>reconstructible</u> if for all posets $\mathbb{P}$ and $\mathbb{Q}$ we have $D_\mathbb{P} = D_\mathbb{Q}$ implies $\alpha(\mathbb{P}) = \alpha(\mathbb{Q})$.

**Examples.** 
1. Number of vertices
2. [[Kelly Lemma]]: number of [[Subposet|subposets]] isomorphic to the given order
3. [[Number of Comparabilities and Degree of Missing Element are Reconstructible]]
