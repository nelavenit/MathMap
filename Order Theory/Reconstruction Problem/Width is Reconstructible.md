**Statement.** [[Antichain|Antichain]] is [[Reconstructibility|reconstructible]].
$\blacktriangle$ Antichain is the only [[Partial Order|order]] with every [[Card]] being an antichain. $\boxtimes$ 

**Statement.** The [[Width|width]] of a poset is reconstructible.
$\blacktriangle$ If an order is an antichain, then we reconstruct it by the previous statement. Else, width of a poset is a maximum of widths of its cards. $\boxtimes$
