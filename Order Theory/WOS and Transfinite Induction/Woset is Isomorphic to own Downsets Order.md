**Definition.** Let $\mathbb{W} = (W, \leq)$ be a [[Well-Ordered Set|woset]], the set of all the [[Upset and Downset|downsets]] of $\mathbb{W}$ ordered by inclusion is a well-ordered set [[Order Isomorphism|isomorphic]] to $\mathbb{W} + {\infty}$. 
$\blacktriangle$ From [[Form of Arbitrary Downset of Woset|here]] we know every downset of $\mathbb{W}$ has a form $[0, w)$ for some $w \in W$. So $[0, w) \leftrightarrow w$ would be an isomorphism between $(\{\text{all downsets of } \mathbb{W} \text{ except } W\}, \subseteq)$ and $\mathbb{W}$. To prove this is a simple exercise.
