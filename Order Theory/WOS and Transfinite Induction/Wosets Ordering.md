**Intuition.** We define a relation on [[Well-Ordered Set|woset's]] [[Isomorphism Class|isomorphism classes]] 
$$[\mathbb{W}] \leq [\mathbb{V}] \Longleftrightarrow \mathbb{W} \text{ is isomorphic to some downset of } \mathbb{V}$$
This relation is:
1. [[Reflexivity|reflexive]] (every poset is isomorphic to itself);
2. [[Transitivity|transitive]] (because isomorphisms composition [[Order Homomorphisms Composition is Order Homomorphism|is]] an isomorphism);
3. [[Symmetry and Antisymmetry|antisymmetric]] (proved [[Wosets Comparison Antisymmetry|here]]);
4. [[Linear Order and Chain|linear]] (proved [[Wosets Comparison|here]]);
5. [[Well-Founded Order|well-founded]] (proved [[Wosets Class is almost Well-Founded|here]]).
However, neither any isomorphism class (except $\mathbb{W} = \emptyset$), nor the quotient class of wosets by [[Order Isomorphism|isomorphism]] is a set – it would contradict the Axiom of Regularity of ZF. So (1)-(4) are just the properties of a proper class, while (5) isn't even a property of a class, but of an arbitrary subset of a proper class.

**Intuition.** The way to see isomorphism classes clearer is to consider certain "canonical" representatives: ordinals (also called ordinal numbers). Ordinals are sets in ZF and are well-ordered sets when equipped with the $\in$ relation.
Moreover, (1)-(4) is true for the class of ordinals with $\in$ relation, and the (5) is true when considering any set of ordinals with the $\in$ relation.
