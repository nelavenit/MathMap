**Definition.** Let $\mathbb{A} = (A, (R_i)_{i \in I})$ be a [[Relation and Relational Structure|relational structure]]. It's called to be <u>connected</u> if its [[Gaifman Graph|Gaifman graph]] $\operatorname{Gf}(\mathbb{A})$ is [[Graph Connectivity|connected]]. Else it's called to be <u>disconnected</u>.

**Definition.** Let $\mathbb{A} = (A, (R_i)_{i \in I})$ be a relational structure, then $S \subseteq A$ is called to be <u>connected in </u>$\mathbb{A}$ if [[Induced Substructure|induced substructure]] $\mathbb{A}|_S$ is connected. 

**Definition.** Let $\mathbb{A} = (A, (R_i)_{i \in I})$ be a relational structure. A set $S$ is called a <u>connected component</u> if it's maximal by inclusion among the sets connected in $\mathbb{A}$. In other words, if it's a [[Graph Connectivity|connected component]] of $Gf(\mathbb{A})$.

**Examples.** 
1. Relational connectivity in [[Graph|graphs]] is exacly the usual graph connectivity
2. Relational connectivity in [[Poset|posets]] is exactly the [[Connectivity]]. Equivalently it is a graph connectivity in [[Comparability Graph|comparability graph]]
3. Relational connectivity in [[Directed Graph|digraph]] is the connectivity of the underlying undirected graph
