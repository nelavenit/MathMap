**Remark.** A <u>class of relational structures</u> is a set-theoretic class whose members are [[Relation and Relational Structure|relational structures]]. So it can be a set and can be a proper class, hence we should be cautious not to do something impossible in ZFC, like, for example, take set of all relations (unless we restrict the [[Relation and Relational Structure|domain]]).
**Intuition.** We want to generalize the ideas of [[Induced Subposet|induced subposet]] and [[Induced Subgraph|induced subgraph]]. We want to say that a relational structures class if heriditary if it's closed under taking induced substructures ()
**Definition.** A class of [[Relation and Relational Structure|relational structures]] $\mathcal{C}$ is called <u>heridetary</u> if every [[Induced Substructure|induced substructure]] of any member of $\mathcal{C}$ belongs to $\mathcal{C}$.
